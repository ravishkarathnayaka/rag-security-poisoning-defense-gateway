THREAT CATEGORY ATTACK MECHANISM VULNERABLE RAG IMPACT SENTINEL DEFENSE MITIGATION
Indirect Prompt Injection
OWASP LLM01 		Adversarial instructions concealed within third-party documents (PDF, Markdown, HTML) designed to commandeer model behavior. Model abandons system instructions, leaks confidential chat history, or executes unauthorized tool calls. Dual-Pass Ingestion & Runtime Classifier: High instruction density pre-filtering at intake; runtime injection detection quarantines chunks.
Vector Database Tampering
OWASP LLM04 		Direct offline manipulation of stored vector embeddings or SQLite storage records out-of-band. Poisoned chunks enter retrieval results without passing ingestion filters. HMAC-SHA256 Cryptographic Provenance: Every chunk is signed at ingestion. Modified chunks fail HMAC verification and are quarantined.
Unicode & ASCII Smuggling
Obfuscation Attack 		Inserting zero-width characters (\u200B), Bidi overrides (\u202E), or Cyrillic homoglyphs (\u0430) to hide words. Bypasses naive regex keyword filters while remaining fully readable to subword tokenizers. Multi-Stage Sanitizer: NFKC normalization, zero-width stripping, and Cyrillic/Greek-to-Latin homoglyph mapping.
Delimiter Boundary Breakout
Context Hijack 		Injected chunks insert counterfeit closing tags (</untrusted_retrieved_context>) to break out of data delimiters. Parser treats attacker text as top-level system instructions. Strict Delimiter Escaping: All boundary tags inside chunks are automatically escaped to safe XML entities (&lt;/...&gt;).
